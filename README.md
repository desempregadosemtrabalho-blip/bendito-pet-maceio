# Bendito PET Maceió

Landing page estática e responsiva da Bendito PET Maceió, construída com HTML, CSS e JavaScript puros.

## Publicação na Vercel

O projeto já está configurado para publicação direta pela Vercel:

- Framework Preset: `Other`
- Build Command: deixar em branco
- Output Directory: definido automaticamente como `dist` pelo `vercel.json`
- Install Command: deixar em branco

Ao importar este repositório na Vercel, basta manter a raiz do projeto e iniciar o deploy.
